BFS(G, start)

1. for each vertex v in G
2.     visited[v] = false

3. create an empty queue Q

4. visited[start] = true
5. enqueue(Q, start)

6. while Q is not empty
7.     u = dequeue(Q)
8.     print u

9.     for each adjacent vertex v of u
10.         if visited[v] == false
11.             visited[v] = true
12.             enqueue(Q, v)
